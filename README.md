## 🛠 Portfolio Local Setup

This portfolio is built with Next.js 16 and optimized for peak performance and SEO.

### Prerequisites
Make sure you have Node.js 20+ installed.

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/AnkitRaj20/portfolio-nextjs.git
   cd portfolio-nextjs
   ```

2. **Install dependencies**
   ```bash
   npm install --legacy-peer-deps
   ```

3. **Set up Environment Variables**
   Create a `.env` file in the root directory and add:
   ```env
   RESEND_API_KEY="your-resend-key"
   NEXT_PUBLIC_GA_ID="your-google-analytics-id"
   ```

4. **Run the development server**
   ```bash
   npm run dev
   ```
   *Open [http://localhost:3232](http://localhost:3232) with your browser.*
